# Whole-brain MERFISH 8.4M integration

This bundle contains representative spatial and embedding panels from the 8.4M mouse whole-brain MERFISH integration evaluation.

The main analysis entry point is
`../../scripts/merfish_whole_brain/run_merfish.py`.

Results:

- `merfish_coronal_pair.png`
- `merfish_sagittal_pair.png`
- `merfish_umap_pair.png`
- `umap_major_brain_region.png`
- `umap_source_h5ad.png`
- `umap_brain_section_label.png`
- `merfish_metrics.json`
- `merfish_source_metrics.csv`
- `run_settings.json`

The panels show broad neuroanatomical organization, sub-regional spatial
structure, and source-level embedding mixing.
