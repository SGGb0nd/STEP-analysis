# STEP complete-neighborhood controls

This workflow compares the manuscript's sampled STEP results with matched
complete-neighborhood mini-batch training for the five CRC sections and four
prostate sections. Both training paths use complete-section graph inference.

Each dataset directory contains compact assignments, section-level metrics,
run settings, the high-resolution spatial comparison, and the appendix-sized
figure. Full embeddings and optimizer checkpoints are regenerated by
`scripts/validation_controls/step_fullgraph_prostate_crc.py` and are not stored
in this repository.
