# MOSTA Liver validation

`biological_evidence/` contains literature-marker associations, section-domain
composition, DEG and pathway tables, and their spatial figures.

`cross_section_transfer/` contains leave-one-section-out predictions,
per-domain metrics, confusion matrices, feature tables, and classifier-weight
summaries.

`composite/` combines the spatial marker, domain-composition, pooled odds-ratio,
transfer-metric, and held-out spatial-prediction panels.
