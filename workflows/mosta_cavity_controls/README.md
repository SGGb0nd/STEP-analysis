# MOSTA Cavity controls

`method_comparison/` contains matched-spot assignments and Cavity metrics for
STEP, NicheCompass, BANKSY, GraphST, and STAGATE across five E16.5 sections.
The GraphST and STAGATE results compare full-graph and sampled training.

`local_signal/` contains the controlled no-graph dispersion and finite-hop
Gaussian smoothing experiment. The saved metrics support both the spatial
panels and the aggregate Cavity F1 panel.
