# External spatial-domain cluster plots

These panels show the aligned spatial-domain outputs used for the CRC Visium
HD, MOSTA E16.5, and prostate Slide-seq V2 comparisons. The corresponding
plotting and alignment code is in
`scripts/external_benchmark/plot_external_method_clusters.py`.

CSV files retain the plotted Slide-seq coordinates and cluster assignments.
PNG and PDF files are raster and print versions of the same panels.
