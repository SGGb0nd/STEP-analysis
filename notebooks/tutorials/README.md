# STEP tutorials

Executed notebooks demonstrating STEP workflows across spatial transcriptomics
technologies and analysis scales.

Source accessions and the expected local data layout are listed in
[`../../docs/data_accessions.md`](../../docs/data_accessions.md).

## Core tutorials

| Notebook | Workflow |
|---|---|
| `DLFPC.ipynb` | 10x Visium spatial-domain identification |
| `liver_visium_BA_normal.ipynb` | Human liver spatial domains, zonation, and deconvolution |
| `MERFISH.ipynb` | MERFISH cell-state and spatial-domain analysis |
| `human_colorectal_cancer.ipynb` | Visium HD colorectal-cancer analysis at 16 um |
| `mouse_small_intestine.ipynb` | Visium HD cell-type and spatial-domain analysis at 8 um and 16 um |
| `scRNA-seq.ipynb` | Single-cell RNA-seq integration |

## Representation and microarchitecture tutorials

| Notebook | Workflow |

| `crc_visium_hd_representation.ipynb` | Joint CRC Visium HD representation and spatial domains |
| `crc_visium_hd_microarchitecture.ipynb` | CRC microarchitecture and ligand-receptor analysis |
| `prostate_slideseq_v2_representation.ipynb` | Joint prostate Slide-seq V2 representation and spatial domains |
| `prostate_slideseq_v2_microarchitecture.ipynb` | Prostate microarchitecture and ligand-receptor analysis |
